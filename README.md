# سوالف - لعبة برا السالفة

لعبة جماعية استنتاجية متعددة اللاعبين (نسخة الويب من لعبة برا السالفة / Spyfall) تعتمد على الذكاء، الحوار، وكشف المتسلل.

---

## مميزات التحديث والتصميم

- **تصميم مينيمايز أنيق**: واجهة عصرية أحادية اللون ومريحة للعين بدون أي تعقيد.
- **بدون ضلال**: تم إلغاء كافة تأثيرات الظلال والتوهج لتوفير واجهة نظيفة ومسطحة وسريعة الاستجابة.
- **بدون ايموجيات**: استبدال كافة الإيموجيات بأيقونات خطية دقيقة وأوصاف نصية مباشرة.
- **خادم موحد (Fullstack in One Deployment)**: الواجهة والخادم يعملان معاً على نفس المنفذ دون الحاجة لخدمات منفصلة أو مشاكل CORS.
- **مشاركة سريعة**: إمكانية نسخ رابط دعوة مباشر يفتح الغرفة لأصدقائك بضغطة واحدة.
- **مرونة عدد اللاعبين**: إمكانية بدء اللعبة من لاعبين وحتى 12 لاعباً.

---

## التشغيل المحلي

### الخيار 1: عبر الملف التلقائي (Windows)
فقط انقر نقراً مزدوجاً على:
```
start.bat
```
سيقوم ببناء الواجهة وتشغيل الخادم تلقائياً على: `http://localhost:3001`

### الخيار 2: عبر الأوامر (Terminal)
```bash
# تثبيت التبعيات
npm install

# بناء الواجهة
npm run build

# تشغيل الخادم والواجهة معاً
npm start
```
افتح المتصفح على: `http://localhost:3001`

## النشر في خدمة واحدة (One-Click Deploy)

يمكنك نشر المشروع كاملاً كخدمة ويب واحدة (Single Web Service) على أي منصة استضافة مثل **Render** أو **Railway** أو **Fly.io** أو **VPS**:

### النشر على Render:
1. أنشئ حساباً مجانياً على [Render.com](https://render.com).
2. اختر **New +** ثم **Web Service**.
3. اربط مستودع GitHub الخاص بهذا المشروع (`swalef-2s1`).
4. الإعدادات المطلوبة:
   - **Environment**: `Node`
   - **Build Command**: `npm run build`
   - **Start Command**: `npm start`
5. اضغط **Deploy Web Service**.

> سيعطيك Render رابطاً عاماً مثل `https://swalef.onrender.com` يخدم الموقع وقاعدة البيانات وخادم Socket.io في آن واحد.

## خطوات اللعب مع الأصدقاء بسلاسة

1. **تسجيل الدخول**: يقوم كل لاعب بإنشاء حساب أو تسجيل الدخول باسمه المستعار.
2. **إنشاء الغرفة**:
   - يضغط أحد الأصدقاء على **إنشاء غرفة جديدة**.
   - يحدد فئة الكلمات (طعام، مهن، حيوانات، أماكن، عام... إلخ).
3. **دعوة الأصدقاء**:
   - يضغط المضيف على زر **نسخ رابط الدعوة** أو يشارك كود الغرفة المكون من 6 أحرف.
   - يفتح الأصدقاء الرابط مباشرة أو يكتبون الكود في الصفحة الرئيسية للانضمام.
4. **بدء الجولة**:
   - يضغط المضيف على زر **بدء اللعبة**.
   - يرى المواطنون الكلمة السرية الموحدة، بينما يرى المتسلل تنبيهاً بأنه المتسلل ومطلوب منه التظاهر بمعرفة الكلمة وتخمينها.
5. **النقاش والأسئلة**:
   - يسأل كل لاعب لاعباً آخر سؤالاً ذكياً حول الكلمة لا يكشفها للمتسلل ولا يجعله يشك فيه.
6. **التصويت والنتيجة**:
   - بعد انتهاء النقاش، يضغط المضيف على **بدء التصويت**.
   - يصوت كل لاعب على من يعتقد أنه المتسلل.
   - يفوز المواطنون إذا كشفوا المتسلل، ويفوز المتسلل إذا أفلت أو نجح في التمويه!
   - بعد انتهاء الجولة، يمكن للمضيف الضغط على **جولة جديدة** للعب فوراً بكلمة وفئة جديدة.

## هيكل المشروع

```
swalef-2s1/
├── client/              # تطبيق React + Vite
│   ├── src/
│   │   ├── components/  # الأيقونات والمكونات
│   │   ├── contexts/    # سياق المصادقة والاتصال والتنبيهات
│   │   ├── pages/       # صفحات اللعبة (Auth, Home, Waiting, Game)
│   │   └── config.js    # ربط تلقائي ديناميكي للسيرفر
├── server/              # خادم Express + Socket.IO
│   ├── database.js      # محرك قاعدة البيانات المرن (Pure-JS JSON Engine)
│   ├── words.js         # بنك الكلمات والتصنيفات الغنية
│   └── index.js         # خدمة API + WebSockets + ملفات الواجهة الثابتة
├── package.json         # أوامر البناء والتشغيل الموحدة
└── start.bat            # تشغيل محلي بنقرة واحدة
```
