# سوالف - لعبة برا السالفة 🎭

لعبة اجتماعية متعددة اللاعبين مبنية بـ React + Vite + Node.js + Socket.io

## 🚀 طريقة التشغيل

### 1. تشغيل السيرفر
\`\`\`bash
cd server
npm start
\`\`\`

### 2. تشغيل الواجهة
\`\`\`bash
cd client
npm run dev
\`\`\`

افتح المتصفح على: **http://localhost:5173**

---

## 🎙️ إضافة الصوت (Agora RTC) - اختياري

1. اذهب إلى [console.agora.io](https://console.agora.io)
2. أنشئ حساب مجاني
3. أنشئ مشروع جديد واحصل على **App ID**
4. افتح `client/src/pages/GameRoom.jsx`
5. استبدل `'YOUR_AGORA_APP_ID'` بـ App ID الخاص بك

> **بدون Agora**: اللعبة تعمل كاملاً بالشات فقط، الصوت اختياري.

---

## 🎮 قواعد اللعبة

- **المواطنون**: يعرفون الكلمة السرية ويحاولون اكتشاف المتسلل
- **المتسلل**: لا يعرف الكلمة ويحاول التظاهر بأنه يعرفها
- **4-6 لاعبين**: متسلل واحد | **7+ لاعبين**: متسللان
- **الفوز**: المواطنون يكشفون المتسلل بالتصويت

---

## 🛠️ التقنيات المستخدمة

| الجزء | التقنية |
|-------|---------|
| Frontend | React + Vite |
| Backend | Node.js + Express |
| قاعدة البيانات | SQLite |
| الاتصال الحي | Socket.io |
| الصوت | Agora RTC SDK |
| المصادقة | JWT + BCrypt |
